# Contributing

Thanks for your interest in improving this widget.

## Development setup

1. Clone the repository.
2. Run the widget locally:

```bash
python3 ram_widget.py
```

3. Run a basic syntax check before opening a pull request:

```bash
python3 -m py_compile ram_widget.py
```

## Pull requests

- Keep changes focused and small.
- Preserve lightweight behavior (avoid heavy dependencies).
- Update `README.md` for user-visible behavior changes.
